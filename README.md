# AITRI — Final Website Build
Complete static GitHub Pages website.

## Included
Responsive visual homepage, supplied AITRI branding, original science imagery, light/dark mode with saved preference, project page, article system, World Research links, LinkedIn/Instagram/contact, favicon/app icons, Open Graph metadata, ResearchOrganization JSON-LD, robots.txt, sitemap.xml, manifest and 404 page.

## Before custom-domain launch
Replace `YOUR-CANONICAL-DOMAIN.com` in index.html, robots.txt and sitemap.xml with the final primary domain. Configure that domain in GitHub Pages, enable HTTPS, then submit sitemap.xml in Google Search Console.
