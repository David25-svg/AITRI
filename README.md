## IMPORTANT BEFORE CUSTOM DOMAIN / GOOGLE SEARCH CONSOLE
Search all files for:
YOUR-CANONICAL-DOMAIN.com
and replace it with the ONE domain you choose as the official AITRI domain.

The current internal links use `/AITRI/` because the live GitHub Pages project is:
david25-svg.github.io/AITRI/

After moving to a custom domain, change `/AITRI/` paths to `/` (or configure the repository accordingly).

Then:
1. Configure the custom domain in GitHub Pages.
2. Enable HTTPS.
3. Verify the domain in Google Search Console (DNS verification recommended).
4. Submit `/sitemap.xml`.
5. Request indexing for the homepage and key research pages.
6. Redirect every secondary AITRI domain to the one canonical domain.
